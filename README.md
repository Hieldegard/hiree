# Hiree

Помощник для поиска работы. Согласованные требования и последующие этапы — в [PRODUCT.md](PRODUCT.md).

## Текущий этап

Есть локальный веб-интерфейс и экспериментальный сбор первой страницы поиска hh.ru через Chromium. Вакансии сохраняются в SQLite и не дублируются по идентификатору hh.ru. Отображается текст описания и ссылка на оригинал. Формат работы, зарплату и соответствие требованиям пока нужно проверять вручную; автоматической оценки и фильтрации ещё нет. Отправка откликов не реализована.

Реальный сбор в облачной среде ещё не подтверждён: Chromium получил ошибку доверия сертификату при открытии hh.ru. Требуется настроить доверие Chromium к сертификату среды и проверить доступ к сайту и его текущую разметку. Интерактивный вход и использование сессии пока не реализованы. При изменении разметки или ограничении доступа сбор останавливается. Если ошибка произошла после сохранения части вакансий, они останутся в списке.

## Запуск

Нужны Python 3.12 и установленный Chromium. В терминале из папки проекта:

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python -m hiree.app
```

Откройте http://127.0.0.1:8765 на том же компьютере, где запущено приложение. В облачной среде локальный адрес доступен в браузере среды; доступ к нему с пользовательского устройства зависит от настроек среды. Для нестандартного пути к браузеру установите переменную `HIREE_CHROMIUM` перед запуском.

Укажите ссылку на страницу поиска hh.ru и нажмите «Собрать вакансии». Сбор ограничен первыми 20 найденными ссылками на одной странице. Сертификаты должны проверяться обычным образом. При капче, ограничениях или ошибках остановитесь и проверьте сайт вручную.

Данные хранятся вне проекта в `~/.local/share/hiree/`; путь можно изменить переменной `HIREE_DATA_DIR`. Не публикуйте эту папку и данные браузерной сессии. Приложение слушает только локальный интерфейс и рассчитано на одного пользователя.

Проверки: `python -m unittest discover -s tests -v`.
