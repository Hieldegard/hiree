# Hiree

Помощник для поиска работы. Согласованные требования и последующие этапы — в [PRODUCT.md](PRODUCT.md).

## Текущий этап

Есть локальный веб-интерфейс и экспериментальный сбор первой страницы поиска hh.ru через Chromium. Вакансии сохраняются в SQLite и не дублируются по идентификатору hh.ru. Отображается текст описания и ссылка на оригинал. Настройки передают фильтры удалённой работы и дохода в поиск hh.ru; вакансии без указанной зарплаты по умолчанию включаются. Доход после налогов, формат и соответствие требованиям нужно уточнять по каждой вакансии; автоматической оценки пока нет. Отправка откликов не реализована.

В облачной среде тестовый сбор сохранил 20 вакансий при запуске с расширенными разрешениями; в обычном режиме Chromium не доверяет сертификату прокси. На Windows сбор ещё не проверен. Интерактивный вход и использование сессии пока не реализованы. При изменении разметки или ограничении доступа сбор останавливается. Если ошибка произошла после сохранения части вакансий, они останутся в списке.

## Запуск на Windows

1. Установите Python 3.12 с официального сайта python.org; при установке оставьте включённым Python Launcher.
2. На странице репозитория GitHub нажмите **Code → Download ZIP**, затем распакуйте архив в отдельную папку. Не запускайте программу непосредственно из ZIP.
3. В распакованной папке дважды нажмите `start-windows.bat`. При первом запуске он скачает необходимые пакеты и браузер Chromium, поэтому потребуется интернет.
4. Когда появится сообщение `Open http://127.0.0.1:8765`, откройте этот адрес в обычном браузере на компьютере. Оставьте окно программы открытым; для остановки нажмите в нём Ctrl+C.

Если при запуске появится ошибка, сохраните скриншот окна. Первый запуск и сбор на Windows ещё не проверены в реальной системе.

## Запуск на Linux

Нужен Python 3.12. В терминале из папки проекта:

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python -m playwright install chromium
python -m hiree.app
```

Откройте http://127.0.0.1:8765 на том же компьютере. Если браузер Playwright уже установлен отдельно, можно задать его путь в переменной `HIREE_CHROMIUM`.

Укажите ключевые слова, желаемый доход и другие условия в настройках, затем нажмите «Собрать вакансии». Настройки сохраняются локально. hh.ru может включить зарплату до вычета налогов и диапазоны, частично пересекающие заданный порог; прежние результаты не удаляются при изменении фильтров. Сбор ограничен первыми 20 найденными ссылками на одной странице и включает паузы и прокрутку. Это не гарантирует доступ при ограничениях hh.ru. Сертификаты должны проверяться обычным образом. При капче, ограничениях или ошибках остановитесь и проверьте сайт вручную.

Данные хранятся вне проекта в `~/.local/share/hiree/`; путь можно изменить переменной `HIREE_DATA_DIR`. Не публикуйте эту папку и данные браузерной сессии. Приложение слушает только локальный интерфейс и рассчитано на одного пользователя.

Проверки: `python -m unittest discover -s tests -v`.
